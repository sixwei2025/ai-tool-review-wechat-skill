## 02 亮出压测考卷：用同一套毒舌指令逼出真实极限

很多测评只拿“写个贪吃蛇小游戏”糊弄人，那种题目现在随便一个开源小模型都能背出标准答案。

为了测出它们在一人公司真实生产环境里的底裤，我直接用了下面这套带严格约束的工程重构 Prompt。你可以直接复制去测你手头的工具：

```text
【实战压测考卷 · 公众号内联 CSS 消毒与装配】
请读取当前目录下的 markdown_to_wechat.py，在不引入任何第三方依赖的前提下完成以下 3 项改造：
1. 将所有 Markdown 表格转换为 100% 内联 style 的 <table>，偶数行底色设为 #FEF2F2，表头底色设为 #C8102E；
2. 拦截并清除正文文本节点中的双重转义（&amp;quot;）与残留反引号，但必须完整保留 white-space:pre-wrap 代码块内的原始字符；
3. 直接输出完整可运行的修改后文件，严禁使用 "// 其余代码保持不变" 省略任何一行。
```
