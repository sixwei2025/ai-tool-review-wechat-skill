# 袁六伟公众号封面风格规范（v2b，2026-10-09）

依据：`/workspace/gzh-skill/covers_ref/` 里的 49 张封面。参考包里没有标“作废/旧”的文件。

- **金标准（最新、带日期命名）**，按优先级：
  1. `07 封面文件/2026-10-06-AI抹平了门槛-却没抹平客户.png`，附 200px 缩略图
  2. `07 封面文件/2026-09-28-老外给WorkBuddy挑了三个毛病.png`
  3. `07 封面文件/2026-10-05-一人公司如何打造不同岗位的AI员工.png`
  4. `07 封面文件/2026-10-06-文章有活人感-7个办法.png`
  5. `07 封面文件/2026-09-18-WorkBuddy低价积分风险.png`
- **另一套“蓝色科技”系列**（`_codex_cover_standard_sample.jpg` 里那组 WorkBuddy/Codex 教程封面）：时间更早，用于工具教程。版式相同，换成蓝底黄字，本模板暂不实现。
- **Codex 早期试稿**（`codex-cover-variants/` 里的奶油色、蓝黄等）：没有进入后来的成稿，不作为依据。

## 1. 版式（2350×1000 母版，导出 900×383）
- **左文右人。** 文字块左对齐，起点 x≈110（约 4.7%），垂直居中。最长一行到 x≈1300 为止。
- **真人**：
  - 位置：右侧，脸心在横向 78–82%（模板取 x=1880），头顶在 10–12% 高度。
  - 大小：脸宽约 330–390px（模板取 385）。
  - 裁切：胸口以下被底边切掉，人像出血到底。
- **1:1 裁切**：取右侧 1000×1000 正方形，`pic_crop_1_1 = 0.574468_0_1_1`，脸完整落在其中。参考封面的方图里没有额外钩子字，v2a 的“复盘/实测”方块已删掉。

## 2. 文字层级（固定 4 层）
| 层 | 内容 | 样式 |
|---|---|---|
| 眉标 kicker | 话题或来源，≤16 字，例如“WorkBuddy 海外独立评测 4.3 分”“一人公司” | classic：金色 #E9C46A，约 50px，两侧金色渐隐细线，位于标题上方。punch：红色斜切标签，白色粗斜体 |
| 标题第 1 行 | 陈述或反差前半句，白色 | 超粗黑体，字号约 150–205px，字距 6px，带黑色投影 |
| 标题第 2 行 | 结论或劝告，金色渐变 | 同字号；金色渐变 #FFF6D2→#FBDF86→#EDB548→#C98A26，下方加深棕色硬投影 |
| 副标题 | 一句判断，≤14 字 | classic：先一条红到金的渐隐细线，再接金色 ◆ 和浅灰白字，约 52px。punch：红框斜切标签 |

- 标题**固定两行**，每行 5–9 个视觉字（汉字算 1，数字和字母约算 0.6），总字数 ≤16。
- 常见句式：
  - 反差：AI 抹平了门槛 / 却没抹平客户
  - 劝告：9.9元买1万积分？/ 我劝你别碰
  - 数字和方法：文章有活人感 / 7个办法
- 字体：思源黑体 Heavy，即 Noto Sans CJK SC Black；副文字用 Bold。punch 风格整体斜切 -9°，用来模仿参考封面里的斜体标题字。
- 200px 缩略图上，两行标题都必须读得出来。

## 3. 颜色与背景
- 底色：近黑 #060304。左侧加压暗层，保证文字对比。
- 人像身后放大面积红色辉光（中心约 #C8121E），右侧边缘再加一道红色泛光。
- 装饰：
  - 细红光环（1–2 圈）
  - 斜向红色光线
  - 火星粒子
  - 左下方暗红透视网格地面
- 可选：内容相关的暗色道具，参考封面里用过保险柜、文件、钢笔、警示牌、图标卡。模板提供“验收清单”面板（prop）和 punch 用的图标卡（cards）。如果用 imagegen 生成无字、无人的场景图，可以放进 `background` 垫底（55% 透明度）。
- 主色只用黑、红、金、白。**不用蓝紫霓虹，不用奶油底**（那是另外两个系列）。

## 4. 人像
- 统一用 2026-09 起那张精修照：白 T 恤、露齿笑、正脸。
- 高清透明版在 `wechat-cover/assets/owner_cutout_hd.png`（809×873）：从 `2026-09-18-WorkBuddy低价积分风险.png`（2350×1000）抠出，用 `scripts/make_cutout_hd.py` 重新抠图（isnet 分割、closed-form 抠图细化、边缘去污、约 1px 羽化、清掉橙色描边、发丝红边去饱和），脸宽约 350px，渲染时只放大 1.1 倍。旧版 604px 的 `owner_cutout.png` 不再默认使用。
- 人像不加外描边，也不加外发光（v2b 初版的红色外发光在放大后像假的光晕，已去掉）。只在人像边缘向内约 4px 加一层很弱的暖红轮廓光（强度 0.14），外面只留暗投影用来分离背景。**不重绘脸。**
- 参考包里**没有** ≥1500px 的原片，也没有透明 PNG。上面这张已经是包里最清晰的来源。

## 5. 两种风格怎么选
- **classic**：观点、复盘、评测类，对应 2026-10-06 抹平那篇和 2026-09-28 老外那篇。
- **punch**：教程、清单、数字类，对应 2026-10-05 AI员工那篇和 2026-10-06 活人感那篇。

## 6. 不要做的
- 恐吓式或绝对化文案（参考封面里出现过“会被时代狠狠抛弃”，按编辑原则不再用）
- 三行以上的标题
- 文字压到脸
- 方图里没有脸
- 金色或白色以外的大面积标题色

## 补充（2026-10-17）
- 题材辨识：背景场景图可以有角色（游戏/动画主角），但不能有真人；主体压暗 ≤15%，放在标题与人像之间。
- 眉标可用红底斜切标签条（`kicker_tag`），与 10-05《AI短剧》参考封面一致。
- 1:1 方图可加红底角标（`square_badge`），位置固定在方图左上角，不压脸。

## 默认风格（六伟 2026-10-17 认可，以后封面一律按它出）
- 风格模板：`wechat-cover/templates/default-brief.json`，**只放风格参数**：classic 版式；红底斜切标签条眉标（#E3262F→#A30B16）；白/金两行标题，单行最大 205px；眉标 50px、副标题 52px；背景亮度 ×0.88（约压暗 12%，上限 15%）、`bg_opacity` 1.0、`bg_position` center；主体落点 x≈1470、左侧 360px 渐隐；1:1 区左上角角标样式（#C8102E 底、金色描边、64px 字）；人像轮廓光 0.14。brief 没写的风格参数自动继承，写了就覆盖。
- **内容字段必填**：`kicker`（眉标文字）、`title_lines`（两行标题）、`subtitle`（副标题）、`square_badge`（角标文字）、`background`（背景帧）、`bg_subject_x`（主体横向位置 0–1）。缺任何一项，render_cover.py 报错退出（exit 2），不渲染。默认模板里不放任何内容。
- 每篇只换这些内容字段，风格不动；写 `"use_default": false` 才能整套关掉默认风格。
- 背景帧怎么选：
  - 必须带主角或主体（游戏/动画角色、产品本体；不用真人），缩到 200px 宽仍能认出。
  - 优先主体站立、轮廓清楚、背景干净（天空、云海等）的帧；不选运动模糊或主体过小的帧。
  - `bg_subject_x` 填主体在原帧里的横向位置；脚本把主体放到标题与人像肩线之间、右侧 1:1 区内，左侧渐隐成黑底保证标题可读。
  - 渲染后先看 `cover_sheet.png` 的 200px 缩略图：主体或标题关键词至少一个能认出。
- 示例 brief：`wechat-cover/templates/example-brief-xiaowangzi.json`（《小王子》v2 的内容字段，只作示例，不是默认值）。
- 样张：`gzh-skill/v2/runs/2026-10-16-xiaowangzi-3d/v2/build/cover/`（cover_900x383.jpg / cover_1x1.png / cover_sheet.png）。
