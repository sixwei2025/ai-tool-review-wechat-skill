# 封面六套（2026-11-12 立）

> 一套封面一个视觉体系，**同一篇文章换套不换内容、不换照片**。
> 渲染器：`scripts/render_cover_themes.py`（纯 Python + Playwright，0 积分）

## 一、为什么要重做

旧的 `render_cover.py` 的底子是电商爆款风：五段金色渐变 + 3D 立体投影 + 三层红色径向渐变。调参数救不回来，袁总连打三次「还是丑」。

这六套换了范式。依据全部来自实测，不是自己想的：

| 来源 | 拿到的 |
|---|---|
| `op7418/guizang-social-card-skill`（8.1k★） | Editorial / Swiss 双体系 + 10 套配色 token；**「越大越细」**：封面主标题 500 字重 + 宽字距，只有小字才加粗加宽字距 |
| `joeseesun/qiaomu-html-cover` / `poster-studio`（98★） | 0.5 秒停留测试：缩略图里只能有**一个第一视觉所有者**，视觉元素 ≤3 |
| `ponyodong2026/ponyo-cover-anchor-system`（228★） | 点击率 = **信息密度 × 视觉锚点**；冲突型 / 数字型 / 截图型 / 情绪型四模板 |
| 小红书「高级感封面」实拍（2099 / 1254 赞样本） | 高赞的高级感是**纸感底 + 墨色大字 + 极小字标注 + 大留白**，不是荧光大字 |

## 二、六套是什么

| # | key | 名字 | 底 | 墨 | 锚点色 | 字体 | 人像处理 | 适合内容 |
|---|---|---|---|---|---|---|---|---|
| 1 | `midnight` | 午夜墨 | `#0E0D0C` | `#ECE2CF` | `#D4A04A` 暖金 | 宋体 500 | 亮度选择性压暗（白 T 压狠、脸保住） | 数据复盘 / 搞钱 / 深夜长文 |
| 2 | `paper` | 纸本墨 | `#F1EFEA` | `#0A0A0B` | 同墨（纯黑白） | 宋体 500 | 黑白高对比 | 方法论 / 观点 / 教程 |
| 3 | `kraft` | 牛皮纸 | `#EEDFC7` | `#2A1E13` | `#9B5A2E` 焦糖 | 宋体 500 | **暖调低饱和**（复古靠底色） | 个人经历 / 复盘 / 故事 |
| 4 | `indigo` | 靛蓝瓷 | `#F1F3F5` | `#0A1F3D` | `#315D93` 靛蓝 | 黑体 500 | 冷调半去饱和 | AI 工具 / 产品 / 技术 |
| 5 | `swiss` | 瑞士蓝 | `#FAFAF8` | `#0A0A0A` | `#002FA7` 克莱因蓝 | 无衬线 400 | 低饱和彩照 + 顶部 26px 蓝条 | 产品发布 / 清单 / 数据 |

## 三、四条硬规则

1. **越大越细**。主标题 150px / 500 字重，数字行 184px / **400 字重**。字号越大字重越轻，这是 Editorial 和电商风的分水岭。反过来做就是"信息图横幅"。
2. **一套只用一个锚点色**。锚点只出现在三处：kicker 小方块、分隔线、数字行。别再加第二个强调色。
3. **人像满铺 + 局部 tint**。不要"左文右图"两块拼贴。人像是右侧出血满铺，左侧压一层 `paper` 色渐变（34% 实色 → 78% 透明），文字压在渐变上。这样文字和人像是一个画面。
4. **底部必须有 issue strip**。一条发丝线 + 左右两组小字（署名 / 期号）。没有它，横版 2.35:1 会头重脚轻——下半 1/4 全空是"没设计完"的典型味道。

## 四、用法

```bash
# 六套全出（内置样例文案）
python3 scripts/render_cover_themes.py --demo --out out/

# 用自己的 brief，只出其中几套
python3 scripts/render_cover_themes.py --brief cover-brief.json --themes midnight paper --out out/

# 列主题
python3 scripts/render_cover_themes.py --list
```

brief 字段：

```json
{
  "kicker": "知识星球 · 三个月复盘",
  "brand": "WorkBuddy",
  "title_lines": ["全自动运营星球", "3个月18万"],
  "subtitle": "附保姆级实操 · 5 讲全流程",
  "author": "袁六伟",
  "meta": "NO.03 / 2026.11",
  "stamp": "可选：一个描边框里的标注，只有 kraft 有位置"
}
```

`title_lines` 最后一行自动走锚点色 + 更大更细。

每套出两版式：`cover-<key>-wide.png`（2350×1000，朋友圈横版）、`cover-<key>-square.png`（1080×1080，1:1 分享卡），外加 `_portrait-<key>.png`（处理过的人像，可复用）。

**1:1 是单独排版的，不是从横版裁的。** 横版文字右边界只有 937，而裁切线在 1350，裁出来只会得到一张大头照。竖版走 `build_square_html()`：文字在上、人像底部出血。

**封面不写期号编号。** `NO.03 / 2026.11` 这类是设计师的实现细节，不是内容。`strip_right` 默认空，要就显式给。

## 五、自带的硬闸

渲染时自动量 DOM，别关：

- **文字右边界 ≤ 1334**（`SQUARE_X - 16`）。超了 1:1 分享卡会切掉半个字。
- **标题不得压脸**。人像按 alpha 裁边后尺寸变了，`face_box` 必须按**裁后尺寸**重映射，否则这条闸是假的。
- 贴边检查：标题 y < 40 或 y > H-40 会给 warning。

## 六、翻过的车

1. **抠像必须先按 alpha 裁边**（`trim_alpha()`）。不裁的话人像右侧会留一条透明空隙，看起来像没贴到画布边。
2. **白 T 无法靠整体压暗解决**。统一乘 0.74 的话，脸也跟着暗成没气色，白 T 还是画面最亮。正确做法是**按亮度选择性压暗**：`f = 0.98 - 0.46*g`，高光压到 0.52，中间调保住 0.98。
3. **品牌名别拉太宽字距**。`0.30em` 会让 WorkBuddy 变成"逐字念"，`0.13em` 才像品牌字条。
4. **底部左栏别放 kicker 原文**。会跟顶部 kicker 重复，看着像复制粘贴。放署名。
5. **人像是 817×883 的抠像，横版要放到 1140 高**，放大 1.29 倍。再大就发虚，想要更大幅面得回原图重抠（`scripts/make_cutout_hd.py`）。
6. **别把 `default-bg-frame.jpg` 当背景**。那是《小王子》风卡通插画，压暗后仍是童话小人站在草地上。

## 七、怎么选

按内容结构选，不按星期几轮换：

| 内容长什么样 | 用哪套 |
|---|---|
| 带硬数字的结果复盘、搞钱、算账 | `midnight` |
| 讲方法、讲观点、教程清单 | `paper` |
| 讲自己怎么过来的、踩坑故事 | `kraft` |
| 工具测评、产品更新、技术方案 | `indigo` |
| 发布、清单、对比表、纯数据 | `swiss` |
| 要跟正文排版颜色一致、没把握时 | `brand` |

一篇只用一个体系，不要在文章里混。


## 八、🔴 人像绝对不许做黑白

2026-11-12 袁总原话：**「尽量还不要用黑白的嘛，就感觉像我人已经去往西天了一样，人已经挂了」**，紧接着「黑白这个风格去掉」。

真人照片做纯黑白，在中文语境里就是遗像。这条没有商量余地，`portrait="bw"` 从主题表里删了，只剩三个选项：

| 模式 | 效果 | 用在 |
|---|---|---|
| `muted` | 低饱和彩照，保留肤色和血色，只压艳度 | 纸本墨 / 瑞士蓝 / 靛蓝瓷 |
| `warm_muted` | 暖调低饱和，复古感靠底色而不是去色 | 牛皮纸 |
| `warm_dark` | 暗调压光，按亮度选择性压暗（白 T 压狠、脸保住） | 午夜墨 |
| `normal` | 原色彩照轻压暗 | 汇芯红 |

要「高级」「克制」，用**低饱和 + 纸感底 + 宋体 + 大留白**去实现，不要靠抽掉颜色。抽掉颜色只会让人显死。
