# AI工具评测公众号 Skill

合并「写作方法 + 选题→大纲→正文硬闸 + 汇芯红六套排版 + 推草稿箱原则」为一份完整工作流。细节渐进披露到 `references/`；主题骨架在 `themes/`。

## 0. 目标：点开 · 读完 · 转走

新号破万主要靠微信推荐。时间分配建议：选题 50% / 标题封面 30% / 正文 20%。本 Skill 保证每篇具备破万条件；命中率靠复盘抬升，不保证篇篇破万。

## 1. 铁律

1. **只存草稿箱**；群发须负责人批准。本包不附带真实 AppSecret；推箱用你自备的公众号草稿箱 API。
2. 广告由负责人决定；广告稿也必须写真实缺点。
3. **价格/额度只认官网**，写查询日期；冲突未解决不下死价格。
4. **不编**：数字、截图、测试过程、用户反馈、第一人称假经历。
5. **禁引流**：不诱导分享；正文/文末无课程海报与二维码；评论区不做引流；不擅自联系厂商/博主/读者。
6. 登录/付费/敏感材料：先提醒缺什么，再继续。
7. 对外禁止内部黑话与产能揭短（没真跑/太忙/整理型等对外口径）。
8. **洗稿三步**（近一周默认）：提炼对标观点/方法论 → 本机真跑拿手感 → 成稿推箱；禁从 0～1 乱写。详见 `references/15-洗稿三步.md`。
9. **负责人确认/拍板闸**（四步不可跳，见 §2）：选题 → 大纲 → 正文 → 推草稿。
10. **排版零分叉**：默认 **汇芯红 `#C8102E` 六套骨架按天轮换**（`themes/rotation.md`）；禁止把废弃黑金主题当默认。图说走小字灰居中组件；Markdown 图下一行 `（说明）` = 图说。
11. **标题默认过闸**：出题先过 `references/03-标题实验室.md` §0；不过闸不交不推。
12. **标题/钩子/正文持续进化**：翻车当日改 `03`/`04`/`16`/`17`/`18`。详见 `references/17-标题钩子正文持续进化.md`。

## 2. 工作流总闸（每步有产出物）

```
① 选题打分（标真跑/整理）→ 负责人确认/拍板
② 证据包 / 选购资料包 → evidence/
③ 一页纸（独家发现+情绪线+读者+标题8选）→ 负责人确认/拍板
④ 按类型模板写正文（仅当①③两关都过）
⑤ 破万自评≥85 且过证据否决项 → 交稿
⑥ 负责人点名账号后 → 排版 + 推草稿箱（只草稿、不群发）
⑦ 发布后 24h/72h 复盘 → 进化日志
```

**硬禁（并入原「评测号写作硬闸」）**

- 选题未过：不出大纲（可内部备选，未交负责人不算过）
- 大纲未过：**禁止开写正文**、禁止配图终包、禁止推箱
- 负责人直接丢标题/选题时：仍须先出大纲交拍板，不得默认「等于已过大纲」
- 任一步无产出物，不准进入下一步；他说「直接成稿」且选题大纲已过：可跳重复询问，**不可跳证据**

| 步骤 | 必读 | 产出 |
|---|---|---|
| ① | `references/01-选题引擎.md` + `09` | 选题卡 |
| ② | `02` + `11` + `13` | 证据包 |
| ③ | `references/03-标题实验室.md` | 一页纸 |
| ④ | `04` + `05` + `10` + **`18`** + **`20`** + **`21`** | 正文 |
| ⑤ | `06`（含说人话）+ `10` 否决项 | 自评表 |
| ⑥ | `themes/` + 本 Skill §6～7 | 排版 HTML + 草稿 |
| ⑦ | `references/07-复盘进化.md` | 复盘记录 |

模板见 `templates/`；脱敏样例见 `examples/`。

## 3. 账号尺子与内容类型 × 证据匹配

**我们是谁**：替普通人花钱花时间试 AI 的朋友。「我先替你踩坑，你直接抄结论。」

读者优先级：打工人 → 自媒体/副业 → 小老板 → 学生家长 → AI 爱好者（最后）。

人设：真花钱、真翻车、真有态度。公司实操为主干，外证旁证。

检验：不懂 AI 的 35 岁会计能读懂并觉得有用吗？

| 类型 | 证据条件 | 结论边界 |
|---|---|---|
| 真跑评测 | 真实任务+产物截图 | 只覆盖已测范围 |
| 横评 | 同题同验收 | 记条件差异，不以厂商跑分代替 |
| 选购分析 | 官网套餐/限制（可无体验） | **禁止**声称亲测或效果胜负 |
| 教程 | 真实完成一个结果 | 步骤可复现 |
| 整理型 | 官网钉死+轻量真触 1～2 场 | 对外仍是评测文；禁编场次、禁揭短 |

详见 `references/09-真跑与整理分轨.md`、`10`、`11`。

## 4. 一票否决 + 说人话硬闸摘要

### 五个一票否决（不过=不交）

1. 拿掉工具名文章仍成立 → 无独家发现  
2. 前 3 句无「你」或具体场景  
3. 全文无一处失败/缺点（选购分析可改为「已知限制」）  
4. 结尾「各有千秋」无态度  
5. 标题承诺正文未兑现  

另加证据否决：虚构体验；官宣冒充亲测；核心动态事实未核验；隐私泄露。

结构轮换（强制）：成稿前先抽结构牌（`references/16-结构轮换.md`），写入一页纸。禁止连续两篇同开头。

### 说人话硬闸（成稿必过；细则 `references/18`）

- `references/19-三看短标.md` — 三看/目录卡每格 3～6 字独立短义  
- `references/20-一句一段.md` — 一句一段（手机硬闸）  
- `references/21-金句标红.md` — 共鸣/价值金句汇芯红标红（3～6 处）

摘要：

1. **材料先于语气**：≥1200 字须能指出 ≥5 件可核材料；材料不够先缩篇幅或补证据。  
2. **前 6 句内给态度**，但禁「先说结论：/先说判决：」等提示冒号包装。  
3. **禁法官腔**：判决、宣判、裁定、本案、落槌等 → 改为结论/站队/值不值。  
4. **禁翻案腔**：不是…而是…、你以为…其实… 等抬价套。  
5. **正文禁** `——` 与提示性冒号（表格/路径/代码/价格行/URL 除外）。  
6. **禁黑话与口语踩雷**：赋能、抓手、闭环、底层逻辑、降本增效、说白了、本质上、颠覆、炸裂、各有千秋等（全表见 `18`）。  
7. **改稿保真**：可降调不可改褒贬；不编体感/出处。  
8. 交稿前跑 `18` 六十秒自检 + `06`；不过 → 不交。

## 5. 篇幅配图与开头可视化

| 类型 | 字数 | 图 |
|---|---|---|
| 首发快测 | 1200～1800 | ≥6，≥1 GIF |
| 深度评测 | 2000～3000 | ≥10，≥2 GIF |
| 横评 | 2500～3500 | 结论表+每工具≥3 |
| 选购/整理 | 1200～2000 | 官网+真触够用即可 |
| 教程 | 1500～2500 | 每步 1 图 |

真截图/真 GIF → 高质感信息图 → 禁粗糙文字图冒充实拍。图下无来源灰字；Markdown **空 alt** `![](path)`。

**开头可视化优先**：模型/视频/画面感选题，钩子最多 1～2 句后必须上 GIF 或成片大图；禁止前几十行纯字才见第一张图。

写作速查：第一人称写动作；结论紧跟证据（秒/元/次/页）；每 300～400 字一个刺激点；情绪线四选一且中间必有反转（真香/避坑/降焦虑/站队）。

**结尾三件套**：一句话结论 → 一个最小动作 → 一个能站队的评论区问题。可有一句自然转发理由；无二维码、无课程海报、不写点关注。

## 6. 排版：themes/ + 图说小字灰 + 金句标红 + 三看短标 + 一句一段

默认 **2号排版 = 汇芯红主色六套**（`themes/`）：

1. 读 `themes/rotation.md` 取当天骨架 id  
2. 只读对应 `themes/references/theme-{id}.md` + `common-components.md`  
3. 主色板见 `themes/palette.md`（默认 `#C8102E`，可改）  
4. **乱码硬闸检查清单**（推箱前必过）：  
   - 文本 `&quot;` / `&amp;quot;` → `"`  
   - 禁正文残留反引号 `` ` ``  
   - 禁 `*-gradient` → 纯色（如 `#FCA5A5`）  
   - 图说：12px（≤13）+ 灰 + 居中；Markdown 图下一行 `（…）` = 图说组件  
   - 金句：`<strong style="color:#C8102E;font-weight:600;">…</strong>`，3～6 处  
   - 三看短标 3～6 字；一句一段  
5. 推箱前必看手机宽预览（如 375px）；封面建议真人抠像 IP；禁止文末课程海报

废弃：heijin / hongjin / moyured 作默认。

## 7. 推草稿箱（配置与禁群发）

**原则**：只用公众号**草稿箱 API** 推草稿；**禁止群发**。群发须负责人书面批准。

**占位配置**（自行放入环境变量或本地私密配置，**勿提交仓库**）：

```bash
export WECHAT_APPID="你的公众号 AppID"
export WECHAT_SECRET="你的公众号 AppSecret"
# 可选：草稿 media_id 仅运行时产生，勿写入 Skill 或 git
```

建议流程：排版 HTML → sanitize/gate（见 §6）→ 调微信草稿箱新增/更新接口 → `get` 回读确认无乱码 → 停。本开源包**不附带**含密钥的 `publish_remote*.py`；请自备脚本或公众号后台手工粘贴。

遇平台审核/分类器拦截：先检查凭据与草稿接口是否正常 → 停空跑 → 按平台规范重试一次 → 勿改命令绕审。
