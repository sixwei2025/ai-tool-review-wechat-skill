# 按内容选骨架（2026-11-12 起 · 废除按天轮换）

🔴 **旧的「按星期一到星期六轮换」已废止**。六套骨架按当篇评测的**内容结构、信息密度、框架类型**直接选定，一篇一套，绝不混搭。

| 评测题材与内容特征 | 选哪套骨架 (`--theme`) | 中文名 | 开篇专属形态 |
|---|---|---|---|
| **单品深度实测 / 首发快刀斩 / 避坑实录** | `ticket` | 汇芯红·票据 | 门票凭证封面（带星级/编号/等级/撕票线） |
| **多模型/多工具横评 / 年度榜单 / 选型指南** | `magazine-card` | 汇芯红·杂志卡 | 杂志快讯封面（划掉旧认知+红黑大字）+ 横向滑动目录 |
| **Agent Skill 深扒 / 架构拆解 / 深度能力演进** | `classic-edit` | 汇芯红·经典编辑 | 白底红光晕引言卡 + 三列看点卡 + 红底编号章节 |
| **实战工作流复盘 / 团队落地实录 / 长周期追踪** | `journal` | 汇芯红·内刊手记 | 内刊头图卡 + PART 竖线编号章节 + 精简对照表 |
| **极客短评 / 科技评论 / 犀利观点** | `minimal-line` | 汇芯红·极简细线 | 上下细线金句 + 超大水印数字章节（红点睛 ≤3 处） |
| **行业随笔 / 深度思考（图少文精）** | `zen-space` | 汇芯红·禅意留白 | 衬线大字居中金句 + 极简目录（⚠️ 重度清单/横评禁选） |

## 选型纪律

1. **评测号主力三套**：日常 85% 的评测稿集中在 **`ticket`（单测）**、**`magazine-card`（横评/盘点）**、**`classic-edit`（Skill/深度拆解）**。
2. **禁止反问负责人「用哪套」**：根据上表自动匹配并在工作台记录一句选型理由。
3. **强制装配主题外壳**：`markdown_to_wechat_article.py --theme <id>` 只生成基础 token 样式，转换后**必须运行 `scripts/apply_theme_shell.py --theme <id>`** 注入当篇定制的开篇封面/目录/章节头/END，严禁使用默认占位词。
