# 按天轮换（一周约 5～7 篇）

原则：一天换一套骨架；主色永远汇芯红。不必再问负责人。

| 星期 | 骨架 id | 中文名 | 开篇形态 |
|------|---------|--------|----------|
| 周一 | magazine-card | 汇芯红·杂志卡 | 杂志快讯封面 |
| 周二 | classic-edit | 汇芯红·经典编辑 | 引言卡+看点 |
| 周三 | minimal-line | 汇芯红·极简细线 | 细线金句 |
| 周四 | zen-space | 汇芯红·禅意留白 | 衬线大字 |
| 周五 | ticket | 汇芯红·票据 | 门票封面 |
| 周六 | journal | 汇芯红·内刊手记 | 头图卡 |
| 周日 | classic-edit 或 magazine-card | 复用工作日里更贴题材的一套 | — |

同日多篇：第二篇起在剩余骨架里换，仍不重复当天已用。题材极不匹配时可换相邻骨架，交付时在内部 STATUS 写一句理由。
