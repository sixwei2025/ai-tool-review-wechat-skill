# 03 标题实验室：标题和封面决定 30% 的阅读

> 负责人 2026-10-28 固化：成稿**默认**按本文件出题与自检，不必等口头再强调「这个标题不行」。交题前不过闸 = 不算交。

## 0. 成稿默认闸（每次出题必过，不问负责人）

交任何标题给负责人 / 写入草稿前，按序自检：

1. **七要素 ≥2**（推荐 2～3）；只标主要素，不注水。
2. **四维总分 ≥80**（满分 100）；或十分制 **≥7.5**。不达标整条重写，禁止贴正确废话凑分。
3. **流量词**：涉 WorkBuddy / 豆包工作 / 大厂热点等已验证高权词时，**题里必须带上**（尤其 WorkBuddy——公众号与社媒权重极高，是流量担当）。禁止为压字把 WorkBuddy 删掉。
4. **禁中庸解释尾**：高分冲突/留白后禁止续「人还得盯着/人还在场/其实还得…」类说教（8 分可变 5 分）。只加能抬要素的硬钩；宁可不改，不稀释。
5. **禁喊麦夸张**：最 / 最屌 / 炸天 / 封神 / 天花板 / 吊打 / 遥遥领先等 → 直接否决重写。
6. **承诺可兑现**：题里每个承诺正文有证据；未测不写「实测/一天 N 场」。
7. **字数**：≤20 汉字为宜（12～18 更优）；英文品牌名可占位，但仍要可读。
8. **交付**：每篇 **8 备选** → 四维表 → **Top3**；负责人定稿后不改。定稿含截图选项时，回填必须对上他点的字母/原话。

不过闸不得推箱、不得把「将就题」塞进草稿。

## 1. 硬规则
- 不超过 20 个汉字（推荐 12～18 个）。
- 每个备选标注用了哪几招（2～3 招）。
- 每篇出 8 个备选，四维打分，Top3 推荐给负责人，负责人定稿后不改。
- **标题里的每一个承诺，正文里都必须有证据。**
- **WorkBuddy 借势优先**（2026-10-28）：凡正文主产品/主场景是 WorkBuddy，标题默认露出 `WorkBuddy`；优化时先改冲突/悬念/留白，**后**再考虑能否缩短其它字，永不先砍品牌流量词。

## 1b. 七要素（六招 + 借势）
权威：贴标签 / 设悬念 / 造冲突 / 做留白 / 撩色欲 / 送好处 / **借势**。  
评测号成稿通常不用撩色欲，分析市面样本仍标出。每条标题标 2～3 个主要素。

快速口诀：**冲突或留白至少占一个；借势能带则带；相关人群能点则点。**

## 1c. 未见文爆款预判（狂练）
目标：标题一出来、正文未发，就能判断会爆 / 中等 / 难爆。  
练习库：自备「标题狂练」目录（冲≥3000，见缝插针分批，**不做定时例程**）。  
**毕业标准**：交负责人的每个标题≥2～3个七要素才可停练。有后台数据后回填预判对错。

## 1d. 十分制速评（对内口令）
与四维并行可用：满分 10，**<7.5 不交**，≥8 可进 Top3 候选。  
打分只看钩子密度与禁区，不看「写得对不对」。

## 2. 六招（评测号版）

| 招式 | 做法 | 例子（结构示范） |
|---|---|---|
| 贴标签 | 点名一类人，让他觉得「说的就是我」 | 「每周写周报的人，这个功能能救命」 |
| 设悬念 | 只给结果不给原因 | 「用了 3 天，我把它卸了」 |
| 造冲突 | 反常识、对立、站队 | 「免费的赢了 199 的」 |
| 做留白 | 话说一半 | 「这个功能，我劝你先别开」 |
| 送好处 | 免费、省钱、省时间、可直接抄 | 「会员免费领 3 个月，入口在这」 |
| 借势 | 大厂、热点、名人、节点、**高权产品名** | 「WorkBuddy一句话出PPT，敢不敢上台」 |

评测号不用「撩色欲」。

## 3. 八个高命中公式

1. **花钱踩坑式**：花了 [金额]，我劝你 [反常识结论]
2. **数字对比式**：[N] 个 AI 做同一件事，[结果反差]
3. **时间压缩式**：[原本耗时]的活，AI [新耗时]搞定
4. **人群点名式**：[人群]，[某工具/功能]真的该用了
5. **免费入口式**：[工具][功能]免费了，[一个限定/坑]
6. **卸载式**：用了 [N] 天，我 [卸载/退款/续费] 了
7. **替代式**：别再花钱买 [A] 了，[B] 够用
8. **反转式**：都说 [A] 好用，测完我发现 [反转]

WorkBuddy 场景优先叠：**借势(WorkBuddy) + 造冲突/设悬念/做留白**（例：一句话出PPT敢不敢上台；先别卸；想死了的远程）。

## 4. 四维打分（每条满分 100，<80 重写）

| 维度 | 分值 | 问自己 |
|---|---|---|
| 好奇 | 30 | 看到会不会想「为什么？」 |
| 相关 | 30 | 不懂 AI 的打工人会不会觉得跟自己有关？ |
| 利益 | 20 | 点进去能得到什么，钱/时间/避坑？ |
| 可信 | 20 | 有具体数字、有亲身动作，不像标题党？ |

## 5. 标题禁区
- 「震惊」「炸裂」「封神」「天花板」「遥遥领先」「吊打」「最屌」「炸天」等夸张词。
- 「最」「第一」「唯一」「100%」等绝对化用词（广告法风险）。
- 没测却写「实测」「亲测」「一周」「一天 N 场」。
- 只有工具名和版本号：「XX 3.0 评测」。
- 标点堆叠：「！！！」「？？？」。
- **中庸解释尾**：高分冲突/留白题后禁止续「人还得盯着」类正确废话（负责人 2026-10-28）。
- **空喊功能名**：有产品无冲突/无场景/无动作（例：「Workbuddy最屌炸天的功能，独立浏览器」→ 直接重写）。

## 5b. 改标题禁区（负责人 2026-10-28）
- **禁止**往已经有钩子的高分题上贴中庸解释尾（例：在「Genie4来了，真人感比游戏还真」后加「人还得盯着」——8分变5分）。
- 只加能抬七要素的硬钩；不加正确废话、说教收场。
- **禁止**为变短或「更干净」删掉 WorkBuddy 等已验证流量词。

## 5c. 本号反例 → 正例（2026-10-28 下午五篇，固化）

| 场景 | 否决/弱题 | 问题 | 过闸题 |
|---|---|---|---|
| Genie4 | （可留）Genie4来了，真人感比游戏还真 | 已 8 分；勿加解释尾 | 同左 |
| PPT | 职场PPT，WorkBuddy一句话能上台吗 | 偏软偏长 | **WorkBuddy一句话出PPT，敢不敢上台** |
| 文件浏览器 | Workbuddy最屌炸天的功能，独立浏览器 | 夸张+最+无冲突 | **别再桌面里翻半小时，右键直接丢给Buddy** |
| 远程 | 想死了的WorkBuddy远程上线，出门不用带电脑 | 超字、品牌重复 | **想死了的远程上线，出门不用带电脑** |

教训：弱题优先补**冲突/场景动作**；强题只微调、不贴尾巴；WorkBuddy 能留则留。

## 6. 封面文字（配合硬闸 Skill 的封面脚本）
- 封面字 ≤10 个字，和标题互补，不重复。
- 标题讲冲突，封面就放结果数字：标题「花了 199，我劝你别买」→ 封面「退款了」。
- 品牌红做强调，背景有字必须模糊处理。
- 卖结果或冲突，不做 Logo 墙。

|---|---|---|---|---|---|---|---|---|---|
