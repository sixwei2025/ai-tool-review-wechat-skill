# 04 正文模板：按类型选，按情绪线写

## 0. 写正文前的「一页纸」（必须先交）

> **材料先于语气**（`18` §3）：一页纸里的独家发现/翻车点必须能指向证据包里的具体材料；≥1200 字成稿内部须能列出 ≥5 件可核材料，否则先补证据或缩篇幅。

```
【独家发现】一句话，别处搜不到的具体细节：
【情绪线】（选一条）真香型 / 避坑型 / 降焦虑型 / 站队型
【目标读者】一个具体的人：「32 岁，做行政，每周五要交周报」
【他读完能得到】一个结论 + 一个能马上做的动作
【一句话结论】值 / 不值 / 谁该用
【翻车点】至少 1 个：
【标题 8 选】见标题实验室
```

## 1. 情绪线

| 情绪线 | 走向 | 适合 |
|---|---|---|
| 真香型 | 怀疑 → 试一下 → 惊喜 → 「早该用了」 | 免费、替代、效率工具 |
| 避坑型 | 期待 → 掏钱 → 失望 → 「别交智商税」 | 付费会员、过度营销产品 |
| 降焦虑型 | 焦虑 → 看清 → 「原来不用追」 | 大厂发布潮、新概念 |
| 站队型 | 不服 → 硬碰 → 「谁强谁弱一目了然」 | 横评 |

**任何一种情绪线中间都要有一次反转。全程夸或全程骂都不好看。**

## 2. 开头（决定读完率，前 3 句最重要）

前 3 句必须做到：出现「你」或一个具体场景 + 出现工具名或利益 + 留一个钩子。

五种开头，任选一种：
1. **场景代入**：「周五下午 5 点，老板说下班前要一份会议纪要。录音 1 小时 47 分钟。」
2. **结果先行**：「这篇文章的 6 张配图，花了我 0 元，用时 4 分钟。」
3. **反常识**：「我把 199 的会员退了，换回了免费版。」
4. **账单开头**：「上个月我在 AI 工具上花了 486 块。这里面，有 300 块是白花的。」
5. **读者提问**：「后台有 37 个人问同一个问题：XX 到底要不要买？」

禁止的开头：百科定义（「XX 是一款……」）、时间背景（「近年来，AI 发展迅速」）、过程声明（「今天我们来测一下」）、法官腔（「先说判决」）。

第 4～6 句给出**结论预告**（直接说态度，**禁**「先说结论：」「先说判决：」等提示冒号包装）：「值，但只值一半。哪一半，往下看。」详 `18-说人话表达.md`。

## 3. 模板 A：首发快测（1200～1800 字）

1. 开头钩子（3 句）+ 结论预告
2. 它到底是什么（≤3 句，用人话，别用发布会原话）
3. 我测了 [N] 件事（每件：任务 → 截图 → 一句评价）
4. 翻车现场（1 处，截图 + 怎么绕过）
5. 多少钱 / 怎么免费用（官网 + 查询日期 + 入口截图）
6. 一句话结论 + 谁该用 + 评论区问题

## 4. 模板 B：深度评测（2000～3000 字）

1. 开头钩子 + 结论预告
2. 为什么值得测（它解决的是哪个普通人的痛）
3. 我的测试方法（1 段话 + 1 张表：测了什么、怎么测、和谁比）
4. 场景一：最惊喜的一次（细节写透）
5. 场景二：同题对照（并排截图 + 数据）
6. 场景三：翻车（具体到能复现）
7. **独家发现**（文章高潮，单独一个小标题）
8. 算账：价格 × 用量 = 每次多少钱，多久回本
9. 适合谁 / 不适合谁（各 2～3 条，具体到人群）
10. 最小动作 + 一句话结论 + 评论区问题

## 5. 模板 C：横评（2500～3500 字）

1. 开头：一个所有人都会遇到的任务
2. **结论表先行**（第一屏就看到谁赢）

```
| 工具 | 速度 | 准确 | 好不好改 | 价格 | 一句话 |
|---|---|---|---|---|---|
```

3. 测试规则（同一输入、同一提示词，贴原文）
4. 逐题对比（每题并排截图 + 冠军 + 理由）
5. 意外发现（排名之外的东西，通常是独家发现）
6. 按人群推荐：「如果你是 X，选 A；如果你是 Y，选 B」
7. 评论区站队问题

## 6. 模板 D：清单 / 教程（1500～2500 字）

1. 开头：**先展示成品**（「这张图就是 AI 做的」）
2. 你需要准备什么（工具、费用、时间）
3. 步骤 1～N（每步 1 张截图 + 1～2 句话 + 易错点）
4. 我踩过的坑（2～3 个）
5. 提示词原文（可复制，放在代码块或引用块）
6. 进阶玩法 1 个
7. 评论区：「做出来的发评论区，我挑 3 个放下一期」

## 7. 模板 E：避坑 / 翻车（1200～2000 字）

1. 开头：我花了多少钱、多少时间
2. 当初为什么买（宣传怎么说的，截图）
3. 实际怎么样（3 个落差，每个都有证据）
4. 公平地说，它好的地方（1～2 条，保住可信度）
5. 替代方案（更便宜或免费的选择）
6. 结论 + 「你被哪个 AI 坑过？」

## 8. 小标题写法
- 小标题要单独看也有信息：「它会悄悄删掉合同里的违约条款」✅，「功能测试」❌。
- 每 300～500 字一个小标题，读者扫小标题就能知道全文结论。

## 2b. 本号好钩子库（持续追加，只写验证过的）
格式：`日期 | 类型 | 前3句摘要 | 为何有效 | 注意`
（空库待日学/周复盘填充；禁止编造未发效果。对标结构见 §2c，勿冒充本号已验证。）

## 2c. 开头增量（2026-10-28 日学 · 对标可抄结构，非本号阅读验证）
- **身份战绩第一句**（宝玉 PPT）：「我有发言权——做过两个还受欢迎的 Skill」→ 立刻一句结论。适合作者有真交付物时；禁止空吹「深耕多年」。
- **名言/新闻冷开 → 立刻切对立框架**（Newin Arc/WB）：前 2 句可冷，第 3 句必须完成「两种产品哲学」对立（迁新浏览器 vs AI 进旧浏览器），禁冷开后百科慢热。
- **钩子后立刻可视化**：主闸已在 `SKILL.md`「开头可视化优先」；非画面感选题也争取钩子后 1 屏内出现第一张真图，勿前几十行纯字。
- **「我没让它定时 → 它自己拆时间点」**（卡尔灵光）：主动感=未请求的时间切片（问一次→自排多个闹钟/提醒）；比空喊「主动性」可截图。Personal Agent 稿优先留这一拍。
- **手机 PA ≠ 电脑 Agent 物种对立**（卡尔）：第 3 拍可切「电脑要 computer use 捞信息；手机要配置方便且长期有效」——国内优势落到「接得上国民级 App」。
