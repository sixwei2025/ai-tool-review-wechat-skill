# 05 写作手感：像一个替你试过的朋友在说话

## 1. 五条原则

0. **材料先于语气**（human-writing）：没有可核动作/数字/截图，先别堆语气词装活人。
1. **写动作，不写功能**：「我丢了一份 47 页的财报进去」，不写「支持上传文档」。
2. **结论紧跟证据**：每说一个好或坏，下一句就是数字或截图。
3. **一段一件事**：1～3 句一段；但每段都要有信息，不能为断句而断句。
4. **有态度**：爽就说爽，坑就说坑，不和稀泥。
5. **说人话**：术语出现时立刻翻译，「上下文窗口（就是它一次能记住多少字）」。像朋友聊，不像法官宣判或发布会（`18`）。

## 2. 对照表

| ❌ 说明书腔 | ✅ 朋友腔 |
|---|---|
| XX 是一款功能强大的 AI 写作工具。 | 我用 XX 写了 3 份周报，第二份把我老板的名字写错了。 |
| 该工具支持多种格式导出。 | 导出 Word 没问题，导出 PDF 表格全乱，我重排了 20 分钟。 |
| 生成速度较快。 | 38 秒出稿。我泡的茶还没凉。 |
| 总体来说性价比较高。 | 一个月 68 块。每周写 5 篇以上，第二周就回本。 |
| 存在一定的幻觉问题。 | 它引用了一篇论文，我去搜了，这篇论文不存在。 |
| 适合有相关需求的用户。 | 如果你每周开 3 次以上的会，装它。只是偶尔开会，免费版就够了。 |
| 让我们一起来看看效果。 | （直接放图） |
| 先说判决：闭眼入。 | 闭眼入。但有一种会，别开它。 |
| 不是功能弱，而是场景不对。 | 周报场景够用；合同审查我会换别的。 |

## 3. 节奏：每 300～400 字一个刺激点
刺激点可以是：一张图、一个 GIF、一个数字、一次反转、一句金句、一个小标题。
连续 400 字纯文字没有刺激点 = 读者开始滑走。

## 4. 金句
每篇 2～3 句可以被截图转发的话，放在段落末尾，单独成段。
- 「AI 不会替你下班，但能让你准点下班。」
- 「免费的东西最贵的地方，是你的时间。」
金句要从测试结论里长出来，不能硬贴鸡汤。

## 5. 数字的写法
- 用阿拉伯数字：「38 秒」而不是「三十八秒」。
- 用对比让数字有感觉：「2 分 10 秒 → 38 秒」。
- 换算成读者的单位：「每份周报 0.4 元」「每天省下一集电视剧的时间」。

## 6. 公平感（让读者信你）
- 夸的文章里必须有一处缺点；骂的文章里必须有一处优点。
- 说明测试条件：「我用的是免费版」「我的网络是家用宽带」。
- 不确定的地方直说：「这一点官方没说明，我测了 3 次结果都一样。」

## 7. 禁用词表
赋能、颠覆、震撼、炸裂、封神、天花板、强大、全方位、一站式、无缝、遥遥领先、吊打、不得不说、值得一提的是、总的来说、综上所述、让我们一起、在这个 AI 时代、众所周知、毫无疑问、各有千秋、见仁见智。

**法官腔（负责人 2026-10-29）**：判决、宣判、裁定、裁决、本案、落槌。改用结论/站队/怎么选。

**口语踩雷**：说白了、说穿了、本质上、换句话说、意味着什么、这意味着（可改「所以」）、不可否认、不难发现、首先…其次…最后（说明书枚举）。

**商业抬价黑话（增量）**：抓手、底层逻辑、顶层设计、认知跃迁、降本增效、全链路、组合拳、打开想象空间、价值闭环、迭代闭环（非控制回路本义）。

**翻案腔外衣**：不是…而是…、你以为…其实…、看似…实则…等（按动作查，详 `18`）。

完整硬闸与交稿自检见 `18-说人话表达.md`。

**改稿保真（shuorenhua）**：可降调不可改褒贬；成本≠效率≠性能；不编体感；交付前逐句核对删改。


## 8. 内部口径禁区（对外不出现）
「本稿未全量实测」「业务太忙」「整理型」「真跑」「按 Skill 要求」以及任何内部流程词。
做不到的事不写，不是写了再遮掩。

## 9. 排版要点（具体操作见硬闸 Skill）
- 重点句加粗，每屏最多 2 处。
- 不用大段引用块；提示词原文可用引用块。
- 表格不超过 5 列，手机上能看清。
