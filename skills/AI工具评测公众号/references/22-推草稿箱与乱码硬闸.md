# 22 推草稿箱与乱码硬闸（开源版）

## 原则
- 只用公众号**草稿箱**接口（新增/更新/获取草稿）
- **禁止群发**；群发须负责人批准
- 凭据仅放环境变量或本地私密文件，禁止写入本 Skill 仓库

## 环境变量占位
```bash
export WECHAT_APPID="your_appid"
export WECHAT_SECRET="your_secret"
```

## 乱码硬闸检查清单
推箱前对最终 HTML：

1. 文本节点无字面量 `&quot;` / `&amp;quot;` → 换成 `"`
2. 无 Markdown 反引号 `` ` `` 漏进正文
3. 无 `linear-` / `radial-` / `conic-gradient` → 改纯色（如 `#FCA5A5`）
4. 图说：≤13px + 灰色 + 居中
5. 金句标红 `#C8102E` 且不过量（3～6 处）
6. 回读草稿正文，确认无乱码

本包不附带含密钥的推箱脚本；请自备或用公众号后台。
