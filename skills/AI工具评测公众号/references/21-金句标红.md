# 21 · 金句标红（汇芯红，负责人 2026-10-29）

## 什么是金句
读者想**截图转发**的共鸣句 / 价值短句：扎心账单感、花钱真相、值回票价、人机关系翻转、普通人捡便宜等。不是夸张口号，也不是功能罗列。

## 成稿怎么筛
1. 成稿后扫全文，筛 **3～6 句**（少而准；勿满篇红）。
2. 优先：开头钩子附近、场景痛点、体感结论、文末站队句。
3. 长句可**只标核心短语**（前后保持正文原色），勿整段染色。

## HTML 写法（zen-space / 汇芯红 2号排版 · 7a）
整句：

```html
<strong style="color:#C8102E;font-weight:600;"><span leaf="">整句</span></strong>
```

长句只标短语：把原 `<span leaf="">前后+短语+后</span>` 拆成：

```html
<span leaf="">前半</span><strong style="color:#C8102E;font-weight:600;"><span leaf="">核心短语</span></strong><span leaf="">后半</span>
```

色值固定：**`#C8102E`**，`font-weight:600`。克制：全文仅 3～6 处；已有「点赞在看转发」等组件红字不计入金句配额时可并存。

## Markdown / 源稿
对应句可外包 `**…**`，或加 HTML 注释 `<!--红-->` 便于以后对位；**以排版 HTML 为准推箱**。

## 验收
- 推箱前自检：红标句数 3～6；无满篇 `<strong style="color:#C8102E`。
- pack → update 后 `get --text`：红相关文案均在稿；乱码探针 quot/bt/grad=0。
