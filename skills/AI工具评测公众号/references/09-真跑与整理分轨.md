# 09 真跑 vs 整理型（汇芯硬闸，对外不揭短）

> 来源：负责人 2026-10-28 定。顶尖 skill 的「破万」流程照跑；本文件补业务过满时的产能分轨。

## 1. 对内 vs 对外

| | 对内（选题卡/证据包/自评） | 对外（正文） |
|---|---|---|
| 真跑 | 同题多场、截图齐、可写一天 N 场 | 深测日记，可承诺实测 |
| 整理 | 官网钉死 + 轻量真触 1～2 场真文件 | **同样是评测文**：结论、算账、场景、适合谁 |

**对外禁止**写：「没真跑」「没测完」「业务太忙」「本稿未全量实测」、以及「整理型」「真跑」「硬闸」等内部词。
对外只呈现已核实事实与已上手场景，用决策二极管收尾，不自我揭短。

## 2. 最低证据（整理型）

- 官网价格/免费额度截图 + 查询日期（必有）
- 轻量真触 ≥1 场真实任务（有输入、有输出、有截图）
- 至少 1 个具体坑或边界（可来自真触，也可来自可核官方限制）
- **禁止**编自测场次；禁止把官宣当自测；标题禁止空口「一天 N 场实测」

测不够 → 降级类型与标题，不准用话术掩饰。

## 3. 整理型正文骨架（对外观感仍要精品）

1. 钩子 + 定调（值不值得现在动手）
2. 它是什么 ≤3 句人话
3. 立尺子：本稿只答 2～3 个决策问题
4. 真金白银（官网 + 日期）
5. 轻量真触 1～2 场（有交件写交件）
6. 对照锚（只写已核实差异，不下未跑胜负）
7. 适合谁 / 不适合谁
8. 最小动作 + 评论区一问
9. 决策二极管；对外不写未跑清单

## 4. 选题卡额外字段

每条选题必须标：`真跑` 或 `整理`。
整理型「一页纸」多一行：`【证据清单】官网价图 / 真触场次 / 翻车点来源`。
