## 二、雙水源选题雷达（日常测什么？）

每次启动「评测雷达」时，从以下两个水源交叉锁定高价值选题：

1. **内部真问题水源（`zsxq-cli` 社群痛点）**
   - 扫描 `Workbuddy一人公司营`、`AI指令俱乐部`、`生财有术`、`AI破局俱乐部` 最近 7 天的高频提问与翻车吐槽。
   - 重点抓：「大家都在问某两个工具到底买哪个」「某新模型出来后老工作流崩了」「某项高频苦力活急需新 Skill 替代」。
2. **外部首发与异常爆款水源（`aihot` + `ai-trending-topics`）**
   - 24 小时内国内外大厂发布的旗舰模型、重磅版本更新、新开放的 API/Agent 功能。
   - GitHub Trending / ClawHub / MCP 市场近期飙升的高星 Skill 与工作流插件。

## 三、四大评测赛道与标准化沙盒压测题（Benchmark）

严禁拿“写一首诗”“讲个笑话”测 AI。所有评测必须从以下 **4 大赛道压测题库** 中挑 3–4 个真刀真枪的任务本机跑完：

### 赛道 A：基座大模型与推理/编程模型（Claude / GPT / Gemini / DeepSeek / Qwen 等）

| 压测维度 | 标准压测任务（任选其一真跑） | 核心记录指标（进证据表与正文） |
| :--- | :--- | :--- |
| **1. 去 AI 味中文商业写作** | 给一份满是黑话的原始材料，要求按严格约束（禁破折号、禁“不是…而是…”、段均 45 字）改写成可直发的实战稿 | 约束遵循率（破戒几次）、人味自然度、是否需要二次返工 |
| **2. 复杂工程/单页应用一次跑通率** | 要求单次生成 400+ 行带完整交互逻辑的 HTML/Python 脚本（如本地数据看板、自动化转换工具） | **Zero-shot 一次点亮率**、报错次数、UI 审美与边界 Bug |
| **3. 脏数据/超长文档大海捞针** | 塞入 3–10 万字混杂财报/合同/长聊天记录，提取指定冲突条款并输出严格 JSON | 漏提率、幻觉编造率、长上下文首字延迟（TTFT） |
| **4. 真实 API 算账与速度** | 统计连续调用 20 次的平均耗时、输入/输出 Token 单价、缓存命中折扣 | 单次任务折合人民币几分钱、月均调用 1000 次总账单 |

### 赛道 B：Agent Skills、MCP 与自动化插件（核心护城河）

| 压测维度 | 标准压测任务 | 核心记录指标 |
| :--- | :--- | :--- |
| **1. 安装与鉴权摩擦成本** | 从零执行安装、配置环境变量/OAuth 授权到跑通第一个 Hello World | 耗时几分钟、卡在哪个报错、普通人能不能照着配通 |
| **2. 真实业务端到端交付** | 跑通一个完整闭环（如：读飞书多维表格 → 调模型处理 → 自动写回文档/发通知） | 端到端耗时、产物可用度、是否需要人工擦屁股 |
| **3. 连续调用稳定性（抗崩压测）** | 故意喂入空值、超长文本、特殊字符或连续调用 5–10 次 | 成功率（X/10）、Rate Limit 限流表现、报错提示是否说人话 |
| **4. 综合 ROI 替代账单** | 对比人工手搓或旧方案 | 省下多少分钟、隐性 Token/API 消耗成本 |

### 赛道 C：多模态生成（图像 / 视频 / 语音克隆）

- **图像模型（GPT Image 2 / Midjourney / Flux 等）**：必测 **「中文多字海报排版准确率」**、**「人物多图一致性」**、**「局部重绘听话程度」**。
- **视频模型（Seedance / Kling / Veo / HappyHorse 等）**：必测 **「大动态运镜崩坏率」**、**「手部/物理规律合理性」**、**「口播对口型/音画同步」**、**「抽卡废片率（生成几条才有一条能用）」**。
- **语音模型（Voicebox / CosyVoice / IndexTTS 等）**：必测 **「克隆相似度」**、**「长句换气与停顿机械感」**、**「多音字与中英混读翻车点」**。

### 赛道 D：AI IDE 与宿主智能体（Claude Code / Antigravity / Cursor / WorkBuddy 等）

- **跨文件重构压测**：在真实多文件工程里改一个核心接口，看谁能自动改完所有引用并通过测试，谁在死循环改坏代码。
- **Computer Use / 浏览器接管**：让它自己打开网页查最新价格、填表或截图，统计卡死在验证码/DOM 变化的真实边界。

## 四、公平比较与核价铁律

1. **同题同输入**：横评两个以上工具时，必须使用**一字不差的同一份原始材料与基础 Prompt**，并在正文中贴出 Prompt 原文。
2. **首轮直出 vs 调教后分开写**：先展示第一把直出的真实结果（哪怕翻车），再展示补了一句什么提示词救回来的。
3. **价格与额度只认官网**：
   - 必须写明**官网当前标价（月付/年付/API 每百万 Token）+ 免费额度限制 + 查询日期（如 `官网价 · 11/12 查`）**。
   - 严禁把月费直接等同于单次成本，必须换算成「干完这一单活到底花几毛钱」。
