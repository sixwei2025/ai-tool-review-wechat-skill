## 0. 一句话

像替你踩过坑的朋友在聊：敢下结论，但不是法官宣判；有态度，但不抬杠抬价；有细节，但不假具体。

会计测试仍生效：不懂 AI 的 35 岁会计读得懂、觉得有用。

**优先级**：证据硬闸（真跑/价格日期/不编）> shuorenhua「保事实、不编」> human-writing 活人感句式 > 卡兹克节奏。

## 3. 材料先于语气（human-writing · 动笔前硬闸）

活人感首先来自材料，其次说话位置，最后才是语气。不要靠口头禅、粗口、梗硬装活人。

### 3.1 1200 字以上非虚构：先列 ≥5 件具体材料

内部逐条写出（不交给读者）：每件必须是**可核**的动作/数字/截图/官网条款/失败现场，并注明来源（证据包路径 / 官网 URL+查询日期 / 用户原话）。  
「方便」「保留状态」「能找回」这类抽象想法各解释五遍 ≠ 五件材料。

列不出五件 → **先别写长稿**：能查就查；需用户亲历最多问 3 句；仍不够 → 缩到 ≤600 字短答，或改选购/整理边界（对外禁编场次）。目标字数与「直接写」不能把材料变多。

### 3.2 评测号材料身份（对齐 reality + 本号类型表）

| 身份 | 能写什么 | 不能写什么 |
|---|---|---|
| 真跑产物/截图 | 亲测过程与结论 | 把未跑步骤补成「我试过」 |
| 官网套餐/限制 | 选购分析、已知限制（写查询日期） | 升级成亲测胜负 |
| 厂商自述 | 「官方说…」并标明 | 当作者亲眼见 |
| 推断 | 「我猜…依据是…」 | 写成裸事实 |
| 未知 | 交代一次会影响结论的缺口 | 用「公开资料显示」灌字 |

**整理型**：官网钉死 + 轻量真触 1～2 场；禁编场次、禁对外揭短（见 `09`）。

### 3.3 假具体 / 假口语（human-writing）

- **假具体**：无来源的精确时间、天气、神态、房间摆设、突然原话 → 越具体 AI 味越重；删或换成证据包里真有的。  
- **假口语**：老铁、兄弟们、咱就是说、泡杯茶慢慢说、硬塞粗口/错别字/括号吐槽 → 袁六伟人设不这样说就删。  
- **不要穿论坛服装**：烟头啤酒冷馒头深夜屏幕电话不能凭空顶真实感。

### 3.4 动笔前五问（内部，不交用户）

1. 谁在说？凭什么知道？哪里只是推测？  
2. 什么事让他现在想说？  
3. 手里有哪些动作/数字/失败/代价托住文章？  
4. 对哪一点有明确判断？依据到哪为止？  
5. 读者看完上一段最自然会追问什么？

## 4. 禁止腔调（法官 / 翻案 / 黑话 / 路标）

### 4.1 法官腔（负责人点名 · 态度项否决）

禁（含变形）：判决、宣判、裁定、裁决、本案、被告、有罪、无罪、量刑、落槌、铁证如山（当修辞）。

改用：结论、站队、怎么选、我的取舍、值/不值、谁该用。

❌「先说判决：闭眼入。」  
✅「闭眼入。但有一种会，别开它。」

### 4.2 翻案腔（human-writing · 按动作查，不按单字）

**禁动作**：先立一个读者没有的误解，再推翻给下文抬价。换字面仍算命中。

| 外衣类型 | 例子 |
|---|---|
| 字面翻案 | 不是A而是B；并非A而是B；不在于A而在于B |
| 省字/跨句 | 不是A，是B；不是A。而是B |
| 以为体 | 你以为A其实B；回头才发现；我一直以为…后来才发现 |
| 让转体 | 看似A实则B；表面…实际…；答案恰恰相反 |
| 抬价体 | A不重要，重要的是B；真正值钱的与A无关 |

拆法：正面下判断 → 紧跟证据。只有真走过「我一开始想错了 → 材料改了我」才可写**一次**自我修正，且不用上列套子。  
「不只…还…」正常递进可用；出现在翻案抬价位置按翻案腔处理。

### 4.3 商业 / 模型黑话（绝对禁 · human-writing revision）

赋能、抓手、商业闭环、价值闭环、迭代闭环（非控制回路）、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、认知增量、单点风险、主脊柱、材料锚点。

旧表仍禁：颠覆、震撼、炸裂、封神、天花板、强大、全方位、一站式、无缝、吊打、遥遥领先、不得不说、值得一提、总的来说、综上所述、让我们一起、在这个 AI 时代、众所周知、毫无疑问、各有千秋、见仁见智。

**语境检查词**（只在抬价时改，本义保留）：沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、打法、闭环（控制回路）、不丢（不丢人）。技术「闭环控制」按本义留（shuorenhua editing-guide）。

### 4.4 口语踩雷（卡兹克 / human-writing）

禁：说白了、说穿了、本质上、换句话说、意味着什么、这意味着（可改「所以」/「结果是」）、先说结论、不可否认、不难发现、首先…其次…最后（说明书枚举）、让我们来看看。

### 4.5 洞察路标 / 假深刻 / 结构 AI 味

禁当段首抬价：更微妙的是、还有一层、只说对了一半、值得注意的是、需要指出的是、从某种意义上说、真正的问题是、归根结底、更深一层。

禁抽象名词配戏：时间保管细节、焦虑显出形状、岁月磨平…（无具体事物时）。

禁抒情抬价词堆砌（无具体事物时）：安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开（抽象对象上）。

结构：
- 三项以上同构排比 → 留两项或改成一件事说透  
- 每节末「这才是真正的胜利」式独句复读 → 删  
- 「下面我们深入聊聊」开场预报 → 删，直接碰事情  
- 无对象的「我不是说…」「别误会…」假辩论 → 有真反对意见才写  
- 「」自造金句短语一篇 ≥3 处 → 多半在造金句，拆掉

### 4.6 标点硬禁（正文）

- 禁 `——` / `—` / `–`（路径/代码/表格除外）  
- 禁提示性冒号：「一句话总结：」「核心是：」「先说结论：」→ 改成普通句子  
- 冒号仅允许引出人物直接原话；URL/代码/机器字段除外

## 5. 正向句式（要这样写）

1. **写动作不写功能**：「我丢了 47 页财报进去」，不写「支持上传文档」。  
2. **结论紧贴证据**：好/坏的下一句必须是秒/元/次/页/截图。  
3. **主语和动作先来**：谁做了什么，再接条件与例子；少用「……的，是……」绕弯。  
4. **名词化还原**：「完成了对流程的优化」→「把流程改顺了；省了 X 分钟」。  
5. **一段一件新东西**：同义换说法不算推进。  
6. **判断可以偏**：用「我觉得 / 我踩过」，依据放旁边；无出处不写「专家认为」。声音来自取舍，不靠堆「说真的」。  
7. **情绪用体感**：动作已写出感情就停，别追一句「我当时很震撼」。  
8. **对立面先承认**：先说对方处境合理，再给自己取舍——仍禁止翻案套句。  
9. **讲完就停**：不时代升华、不全文摘要式结尾；可试删最后两段，更有力就提前停。  
10. **一句一段默认仍有效**（长段手机难读，成稿默认一句一段；细则 `20-一句一段.md`），允许长短交错；禁连续十个独句段打鼓点。  
11. **压缩试验**（human-writing）：删掉约三分之一后事实/判断几乎不变 → 保留短版。

## 6. 交稿前 60 秒自检（并入破万 · 不过不交）

- [ ] 材料：长稿能指出 ≥5 件可核材料；无假具体/假口语顶场  
- [ ] 全文无「判决/宣判」及法官隐喻  
- [ ] 无翻案腔（按动作查表 §4.2）  
- [ ] 无 §4.3～4.5 禁词/路标/三项排比抬价  
- [ ] 无「先说结论：」「核心是：」等提示冒号；结论已用普通句子说出  
- [ ] 无正文 `——`（路径/代码除外）  
- [ ] 每段能标出「新增了什么」；注水段已删；压缩试验想过一遍  
- [ ] 夸里有缺点 / 骂里有优点  
- [ ] **保真**：改过的句子未改褒贬方向、未把成本/效率/性能互相顶替、未编新体感（§7）  
- [ ] 读出声：像朋友聊，不像判决书或发布会  
- [ ] **一句一段**：叙述段无多句同段；口令例外已注明（见 `20`）
- [ ] 冷读三问有答案：哪里让人相信作者知道？哪里愿意继续读？哪段像人在处理问题？

## 7. 改稿保真合同（shuorenhua · 改稿/去 AI 味时强制）

默认：在原稿上做最小必要编辑，**不概括重写**；拿不准就留下。

### 7.1 必须保住

- 事实与判断的方向、强度、效果类型；不把几种具体改善概括成「更好」。  
- 谁做什么、数字对应什么、条件、范围、否定、情态、完成状态、比较关系。  
- **成本 ≠ 效率 ≠ 性能**；结果 ≠ 结果说明了什么 ≠ 对谁的能力评价。  
- 责任归属与下一步；清理推销语气时，「谁交付什么」仍要在。  
- 数字、版本、命令、路径、接口名、作为依据的引语/界面文字。  
- 作者的犹豫、合理转场、有意重复；不替作者变得更自信或更像公告。  
- 否定约束一起留：「不是因为权限不足」≠「权限充足」。  
- 进度/次数是信息：「接下来检查」≠「再检查一轮」。

### 7.2 只许这样改

- 删纯招呼、无承诺预告、口头填充。  
- 删只提示写法顺序的成分，保留它引出的内容。  
- 删完整重复（相关/可推断不算重复）。  
- 简化名词化与生硬语序；**不主动换同义词**，不把多词压成一个概括词。  
- 删无依据的读者身份认证语（「你已经是资深专家」）；感受/评价默认保留。

### 7.3 写平实 / 降调（仅当任务明确要求「别吹」「去营销味」）

- 只许降调，不许加强，不改变褒贬方向。  
- 可降：完美融合→融合；极致的效率→很高的效率。  
- 可删：无对象无承诺的口号（「共创美好未来」）。  
- **必须保留**：可核查承诺（「无需改代码」）、首次/排名、效果幅度、作者批评评价、被讨论的宣传措辞。

### 7.4 交付前核对（逐句）

对照每个删改：原文有而改稿无的内容，除非已授权删除或完整重复 → **放回**。  
不确定 → 撤销该处。不靠追加解释掩盖。不编研究/出处/指标/步骤。  
无源「研究表明」：保留归属+论断，必要时正文外注明缺来源；**禁止**去掉归属变成裸事实。

## 8. 改稿顺序（human-writing 七遍 → 评测号四遍）

1. **谁在说 / 材料**：有没有真动作真数字？换模型也能写的段 → 补证据或删。  
2. **有没有往前走**：连续解释同一观点 → 合并；给每段标作用。  
3. **清姿势**：翻案腔、黑话、路标、法官词、假口语、提示冒号、`——`、三项排比。  
4. **结尾 + 保真核对**：试删最后两段；禁时代/文明空收束；跑 §7.4。

新写成稿：§3→§5→§4→§6。改稿去味：§7→§8→§6。
