# 20 · 一句一段（手机阅读硬闸）

> 负责人 2026-10-29：长段落在手机上阅读体验很差。成稿默认**一句一段**；推箱前必须自检。

## 1. 默认规则

1. **成稿默认一句一段**：每个独立完整句单独成段（按句末 `。！？` 切开，保留句末标点）。
2. **长段手机难读**：同一段内堆多句 → 手机屏上一坨，难扫、难停；禁止成稿带着多句同段出门。
3. **不要在逗号/顿号处拆**：只在 `。！？` 处拆；冒号后紧跟解释且同属一句语义的，仍按 `。！？` 拆。
4. **允许长短交错**：短句与稍长句可交替；禁连续十个独句段打鼓点（节奏问题，不是允许长段）。

## 2. 不要拆（例外）

- 图片行 `![](...)`、图说（括号行）
- `##` / `###` 标题（含标题里的 `？！`）
- 三看/目录卡短标
- **口令 / 指令整块**：对话引号或「直接复制」指令区块里，整段口令可保留为一块（口令内可有多个 `？`/`。`）；拆碎后无法复制
- **叙述里嵌套的对话引号**：`“……”` / `「…」` 内部的 `。！？` 不切开；收尾引号不得落成孤立段
- author-bio、空行结构、指令卡片标题 `【…】`

## 3. 推箱前自检

- [ ] 叙述段几乎无「同一段内 ≥2 个 `。！？`」
- [ ] 口令/指令多句同段若保留，须能指出是口令例外
- [ ] `article.md` 与排版 HTML 同步（HTML 正文每个 `<p><span leaf="">…</span></p>` 也一句一段）
- [ ] 未误拆标题 / 图说 / 三看卡

## 4. 与说人话的关系

一句一段管**版式节奏**；`18-说人话表达.md` 管**用词与腔调**。两闸都过才能交稿。
