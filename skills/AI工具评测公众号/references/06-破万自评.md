# 06 破万自评：<85 分不交稿

## 1. 先过五个一票否决（任何一条不过，直接重写）
- [ ] 拿掉工具名，文章不再成立（有独家发现）
- [ ] 前 3 句有「你」或具体场景
- [ ] 全文至少一次翻车 / 缺点
- [ ] 结尾有明确结论，没有「各有千秋」
- [ ] 标题承诺全部有证据兑现

### 1b. 说人话否决（负责人 2026-10-29，**命中任一条 → 态度或文风项计 0，整篇自评不过 / 重写相关句**）
- [ ] 无「判决 / 宣判 / 裁定 / 裁决 / 落槌」及法官隐喻
- [ ] 无翻案腔抬价套（不是…而是… / 你以为…其实… / 看似…实则… 等，**按动作查**）
- [ ] 无「先说结论：」「先说判决：」「核心是：」等提示冒号包装；结论用普通句子说出
- [ ] 无正文 `——` 破折号（路径/代码/表格除外）
- [ ] 长稿（≥1200 字）能指出 ≥5 件可核材料；无假具体顶场
- [ ] 改稿未改褒贬方向、未编新体感（shuorenhua 保真）
- [ ] `18` §6 六十秒自检全部勾选

> 计分：命中法官腔 / 翻案腔 / 提示冒号包装任一项 → **态度（5 分）与合规相关文风一并否决**，即使其他维度满分也不交。

## 2. 百分制

| 维度 | 分值 | 满分标准 |
|---|---|---|
| 选题 | 15 | 选题打分 ≥80，打工人能看懂并觉得有用 |
| 标题 | 15 | 四维打分 ≥85，≤20 字，没有违规词 |
| 开头 | 15 | 前 3 句有钩子，第 6 句前给出结论预告 |
| 独家发现 | 15 | 具体、可复现、搜不到 |
| 证据 | 15 | 截图/GIF 达标，数字具体，有同题对照或真实账单 |
| 节奏 | 10 | 每 300～400 字有刺激点，小标题单独看也有信息 |
| 态度 | 5 | 结论鲜明，公平（夸里有缺点，骂里有优点）；**无法官腔/翻案腔/提示冒号**（§1b） |
| 结尾 | 5 | 结论 + 最小动作 + 好回答的评论区问题 |
| 合规 | 5 | 价格有日期，无编造，无诱导分享，无绝对化用词；说人话禁词表过 `18` |

## 3. 三个读者测试（各写一句结论）
- **会计测试**：不懂 AI 的 35 岁会计，能读懂并觉得有用吗？
- **转发测试**：读者转发这篇，在朋友眼里会显得「懂行 / 会过日子 / 有用」吗？
- **滑走测试**：从头扫一遍，哪一段最可能让人滑走？那一段改了没？

## 4. 交稿格式

```
【自评】88/100
选题 13 | 标题 14 | 开头 14 | 独家 13 | 证据 14 | 节奏 8 | 态度 5 | 结尾 4 | 合规 5
【扣分最多】节奏：第 3 节连续 600 字无图，已补 1 张对比图
【三个测试】会计：通过 / 转发：「会过日子」 / 滑走：第 5 节价格说明太长，已压缩
【独家发现】___
【翻车点】___
【证据包】evidence/2026-10-28-XX/
```

## 5. 常见扣分原因（每次复盘补充）
- 开头写背景，第 5 句才出现工具。
- 独家发现埋在文章最后，没单独给小标题。
- 截图太小，手机上看不清，没有红框标注。
- 价格只写了「月付 XX 元」，没写年付、免费额度和查询日期。
- 用「判决」收束，读起来像法官（2026-10-29）。
- 「不是A而是B」翻案腔抬价，没有正面下判断。
- 材料不足却灌同义解释；用假具体（精确天气/神态）顶真实感。
- 改稿把「大幅降成本」概括成「更好」，或改了褒贬方向（shuorenhua 保真翻车）。
