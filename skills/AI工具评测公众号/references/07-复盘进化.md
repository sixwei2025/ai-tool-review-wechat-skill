# 07 复盘进化：用本号数据让 Skill 越来越准

## 1. 单篇复盘（发布后 24h 和 72h 各一次）

数据来自公众号后台「内容分析」，负责人提供截图或数字，不准估算。

```
【文章】标题 / 发布日期 / 类型 / 情绪线
【24h】阅读 ___ 在看 ___ 转发 ___ 收藏 ___ 评论 ___ 新增关注 ___
【72h】阅读 ___ ...
【流量来源】推荐 ___% / 公众号消息 ___% / 朋友圈 ___% / 搜一搜 ___% / 其他 ___%
【完读率】___%（后台有就填）
【派生指标】
  转发率 = 转发 / 阅读 = ___
  互动率 =（在看+评论+收藏）/ 阅读 = ___
  读后关注率 = 新增关注 / 阅读 = ___
【诊断】
  阅读低 + 推荐占比低 → 点开率问题：查选题、标题、封面
  推荐占比高但不再增长 → 读完率或互动问题：查开头、节奏、结尾
  转发高但阅读低 → 选题人群太窄
【一条结论】下次保持 ___ / 下次改 ___
```

## 2. 十篇大复盘

1. 按阅读排序，取前 3 和后 3。
2. 对比选题类型、标题公式、情绪线、开头方式、发布时间、篇幅。
3. 找出 **1～3 条本号规律**，必须写成可执行规则，例如：
   - 「免费型选题平均阅读是深度评测的 2.3 倍 → 每周至少 2 篇免费型」
4. 写回：
   - `01-选题引擎.md` 第 6 节「本号爆款选题库」
   - `03-标题实验室.md` 第 8 节「本号已验证公式」
   - `06-破万自评.md` 第 5 节「常见扣分原因」
5. 规则和真实数据冲突时，**以本号数据为准**，改 Skill。

## 3. 对标拆解（每周 1 次）

找 3 篇同赛道近 7 天的高阅读文章，每篇记录：
```
标题 / 账号 / 阅读（页面可见数字）/ 选题类型 / 标题招式
开头前 3 句原文
独家发现是什么
翻车写法
结尾问题
我们能借鉴的 1 点 / 我们能做得更好的 1 点
```
写入工作区「对标拆解」目录。只借结构和角度，不照搬文字。
