# 16 结构轮换（防模板化）

负责人 2026-10-28：近稿壳子太像，要灵动，质量不降。

## 质量常量（每篇都要）
1. 开头有「你」/场景/利益
2. 中间有真数字或官网钉死的限制
3. 有翻车或边界
4. 结尾有态度（禁「各有千秋」）
5. 结论意图 + 可执行动作 + 可站队问句（可合并，不强制三个 ##）
6. 说人话：无法官腔/翻案腔/提示冒号；材料先于语气（`18`）

## 成稿前先抽结构牌（写入一页纸）
| 维度 | 本篇选项（圈一） |
|---|---|
| 开头 | 场景 / 结果先行 / 反常识 / 账单 / 读者提问 |
| 中段 | 时间线 / 对照线 / 问题线 |
| 适合谁 | 独立段 / 嵌倒数第二段 / 三行表 / 评论区顺带 / 本篇省略改用「只做一件事」 |
| 收束 | 三段分列 / 并成一段 / 动作提前到文中 |
| 情绪线 | 真香 / 避坑 / 降焦虑 / 站队 |

**硬禁**：连续两篇同一开头类型；连续两篇出现「适合谁，不适合谁」「结论与最小动作」作为 ## 标题；小标题写成「怎么开做」「功能介绍」说明书题；收束 ## 禁用「判决」「宣判」（用结论/站队/怎么选）。

## 小标题
单独看也有信息量；扫目录能还原结论。

## 中段节奏增量（2026-10-28 日学）
可在「对照线 / 问题线」上叠双刺激，勿与昨学「同镜分维」复读：
1. **任务数字墙**：先给可核件数墙（如 3 个视频 / 600 条高赞 / 情绪占比%），再讲机制。
2. **走查前后对照**：同一任务错误数字 → 修复 → 复查正确数字（如总价 88→176），刺激点=发现 bug，证据=第二轮清单。
来源：有新 Newin《Arc…WorkBuddy…旧浏览器》（2026-10-28）。

## 中段节奏增量（2026-10-29 日学）
可在「时间线 / 对照线」上叠，勿与「数字墙→走查」「办事/管事二分」复读：
1. **接入难度阶梯**：按扫码 → 授权链接/码 → 自申请 Key/MCP 升序拆服务；每档给 1 个真查询截图，中段可甩一整段可复制配置提示语当资产。
2. **偏见翻盘收束**：开篇偏见（以为换壳/配几个 working Agent 就行）→ 接完/测完改主意；刺激=立场反转，证据=件数或物种差异。
3. **可选叠**：先「行业热度 ≫ 普通人获得感」反差，再进非生产力生活实例（阑夕轴）。
来源：卡尔《15个国民级App…》、阑夕《也太爱管闲事》（2026-10-28 文 / 2026-10-29 日学）。
