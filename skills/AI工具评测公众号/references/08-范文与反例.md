# 08 范文与反例

> 下面是**结构示范**，产品名用「X 工具」代替，数字为示意，不是真实测试结果。真实写作必须替换为证据包里的数据。
> 负责人提供真实范文后，放到第 3 节「本号范文」，优先级高于本页示范。

## 1. 反例：说明书腔开头（不要这样写）

> 近年来，随着人工智能技术的快速发展，AI 办公工具层出不穷。X 工具是一款功能强大的 AI 会议助手，支持语音转写、智能摘要、多语言翻译等功能。今天我们就来测试一下它的表现。

问题：
- 前 3 句没有「你」，没有场景。
- 「快速发展」「功能强大」都是空话。
- 「今天我们来测试一下」是过程声明。
- 拿掉「X 工具」，换成任何一个会议工具都成立。

## 2. 正例：同一题的改写（示范结构）

**标题**：开会别再记笔记了，但这种会千万别用它（造冲突 + 做留白 + 贴标签）

> 上周五，一个 1 小时 47 分钟的会。
>
> 散会时，同事还在对着手机录音发愁。我的会议纪要已经发到群里了。
>
> 用的是 X 工具，免费版。
>
> 日常例会，闭眼用。但有一种会，我劝你千万别开它。
>
> 是哪种会，文末说。

（↑ 场景 → 结果反差 → 工具名 + 利益 → 结论预告 → 留白钩子，5 句完成。）

**正文小标题示范**：
1. 1 小时 47 分钟的录音，它用了 3 分钟
2. 它比我自己记得还准的地方
3. 翻车：它把「下周不做」听成了「下周就做」
4. 独家发现：多人同时说话时，它会悄悄合并成一个人
5. 免费版够不够？我算了一笔账
6. 这种会，千万别用它

**结尾示范**：

> 每周开会超过 3 次，装它；涉及人事和合同的会，关掉它。
>
> 今天下午的例会，就拿它试一次。
>
> 你们公司开会，现在是谁在记纪要？评论区说说，我挑最惨的一个，下期送一个月会员。

（注：送会员类活动需要负责人批准后才能写。）
