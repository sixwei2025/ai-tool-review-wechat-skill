# 03 · 视觉配图、实操截图卡与动图（GIF）规范

> 🔴 **2026-11 视觉第一铁律**：
> **真实实测截图 / 真实录屏 GIF ＞ 官方数据原图 ＞ 结构化数据卡**。
> **全面禁用 AI 插画与小黑图**：评测号读者只信真凭实据，绝不用 AI 生成的科幻插画或概念图凑数。

## 一、素材从哪里来？（四大正规水源）

### 1. 本机一手真跑截图（占全篇配图 70%+，每篇 8–12 张）
- **终端 / CLI 实测**：命令执行过程、耗时统计、Token 消耗回执、成功/报错日志。
- **IDE / 桌面端 / 网页工作台实测**：同题输入与输出界面、生成结果预览、多窗口并排对照。
- **性能与账单后台**：OpenRouter / 百炼 / 官方 API Billing 扣费明细、首字延迟（TTFT）与吞吐量实测面板。

### 2. 高信息量动图 GIF（每篇 1–3 处，首屏钩子后必放 1 张）
评测文章有动图，说服力翻倍。动图从以下 3 种方式获取：
- **流式生成速度 PK 录屏**：用无头浏览器（Playwright / Chrome）或屏幕录制，把两个模型同时吐字/跑代码的过程录成 3–6 秒短视频，转成 GIF。
- **多步操作连拍合成**：把连续 3–5 张关键步骤截图用 `ffmpeg` 合成为带停留节奏的轮播 GIF。
- **多模态成片切片**：测视频/动画模型时，直接用 `ffmpeg` 截取最具代表性的 3 秒高光或翻车片段转成 GIF：
  ```bash
  # 标准高清小体积 GIF 转换命令（调色板优化，控制在 3MB 以内适配微信）
  ffmpeg -y -i input.mp4 -vf "fps=12,scale=640:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128[p];[s1][p]paletteuse=dither=bayer" output.gif
  ```

### 3. 官方一手技术报告与权威第三方榜单（占 15%）
- 官方 Technical Report / System Card 中的架构拆解图、官方定价套餐页截图（必须裁掉无关导航栏，保留价格与限制小字）。
- 权威独立基准：LMSYS Chatbot Arena 盲测榜、Artificial Analysis（速度 vs 价格散点图）、SWE-bench 真实得分表。

### 4. 结构化数据卡与横评表（占 15%，无界面可截时补位）
- 当展示多维评分、成本算账公式、选型路由时，优先使用当前汇芯红骨架内置的 **斑马纹表格 / 两列或三列数据卡 / 对比摘要卡**。
- 若需独立可视化图表（折线/柱状/气泡对比），渲染为白底 + 汇芯红 `#C8102E` + 深炭黑 `#1C1917` 的干净图表，并在图说注明「实测数据整理」。

## 二、实操截图卡「七要素」标准（严禁裸截图直接进正文）

任何本机截图进正文前，必须满足以下处理标准（可调用 `make_shot_card.js` 或 Pillow 脚本加工）：

1. **先裁噪音**：裁掉浏览器多余标签页、书签栏、半截无关卡片、左侧无关历史会话列表。
2. **隐私红线打码**：API Key、手机号、邮箱、服务器真实 IP、未公开客户名、左侧其他私有星球/项目名必须彻底裁掉或高斯模糊遮挡。
3. **统一汇芯红描边与高亮框**：用 `#C8102E` 红框精准框出读者最该看的那一行数字、报错或结论（一张图最多 1–2 个框，不遮挡原文）。
4. **序号/结论角标**：多步操作或 A/B 对比时，在左上角或高亮处加清晰的序号标签（① / ② 或 `Claude` vs `GPT`）。
5. **手机 375px 可读性硬闸**：超长页面必须拆取局部核心区，严禁把整张 4K 大屏缩成手机上完全看不清字的细条。
6. **有输入必有输出**：只有 Prompt 输入框没有模型返回结果的截图，不算有效证据。
7. **逐张肉眼核验**：脚本生成或转换后，必须实际查看图片像素，确认无破图、无黑边、框线未偏位。

## 三、封面规范（黑红金 v2b / 评测高客单价风）

1. **尺寸与比例**：母版 2350×1000（导出 `900×383` 横封面 + `1:1` 方图），由 `wechat-cover-skill` 渲染并过 DOM 几何硬闸。
2. **文案三行结构（与文章标题互补，严禁原样重复标题）**：
   - `kicker`（眉标 ≤16 字）：如 `AI 实测实验室 · 042 期`
   - `title_lines`（两行大字，每行 ≤9 视觉字）：第一行白字摆反差/动作，第二行金字给硬核结论（例：`连测 4 款编程 AI` / `最火的被我退了`）。
   - `subtitle`（副标 ≤14 字）：如 `附完整压测题与平替清单`
3. **主号 vs 2号人像策略**：
   - 发**主号 (`main`)**：必须使用袁总真实高清抠像（`owner_cutout_hd.png`），右侧露出完整头部，方图裁剪区完整包含人脸。
   - 发 **2号 (`hao2`)**：可使用真人抠像，或使用无真人的高质感科技器物/被测产品对决视觉帧，200px 缩略图下两行大字必须一眼看清。

## 四、图说与 Markdown 引用细则

1. **正文图片路径一律用 basename**：Markdown 内写作 `![图说](01-claude-vs-gpt.png)`，图片文件与草稿同级或放在 `assets/` 下，推箱脚本会自动平铺上传并替换为微信 CDN URL。
2. **图说样式硬闸**：如果需要图说，必须渲染为 **12px（≤13px）、居中、浅灰（`#9CA3AF` / `#A3A3A3`）**，只写「这是什么结果/哪一轮对比」，严禁写「本机截图」「由于登录墙没截到」等内部取证过程。
