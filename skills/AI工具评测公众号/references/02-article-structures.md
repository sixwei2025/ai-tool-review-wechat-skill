# 02 · 文章结构与四大实战模板（2.0 高密度版）

> 🔴 **2026-11-13 袁总定调（评测叙事主线升级）**：
> 1. **彻底不写「踩了什么坑」**：以后所有评测内容，关于“踩了什么坑 / 报错翻车 / 避坑实录”一律不用说了。对读者和用户而言，最核心的价值是**刚开始直接释放结果 → 过程中手把手告诉他使用方法（配可复制原件） → 最后稍微延伸讲一下底层原理和人文思考**。
> 2. **彻底废除「按句号切开、一句一段」**：段落统一按 **2–3 行自然短段（40–60 字，校验上限 ≤80 字）** 切分，严禁出现连续 3 段 ≤15 字的电报碎句。
> 3. **清爽视觉铁律（零图注 + 禁「原件一二三」拥挤框）**：配图下方**一律不加灰色小字图注**；凡是高清配图/信息卡已经展示清楚的内容，**严禁在下方再塞 `【原件 1/2/3】`、`【速查卡】` 等拥挤的重复文字框**！需要给读者复制的终端命令只留 1–4 行纯命令，搭配 1 张清爽的 Markdown 对比表即可。
> 4. **开篇三件套去重硬闸**：骨架自带的「开篇卡金句」→「目录/看点」→「第一章标题」→「正文首段」，四者语义必须层层递进，严禁把同一句话车轱辘说三遍。

---

## 一、四个一票否决项（触犯任意一条直接打回重写）

1. **无独家发现**：把文章里的模型/工具名字挡住，整篇话依然成立（全是正确的行业废话）。
2. **开篇慢热无结果**：前 2 段还在背诵“随着 AI 大模型飞速发展”，没有第一时间把跑通后的惊艳结果摆上桌。
3. **结尾和稀泥**：横评结尾写“各有千秋，大家按需选择”，不敢明确给出「谁现在立刻用哪款」的清晰选型结论。
4. **无原件可拿走**：通篇只顾着自己嗨聊感受，读者读完连一条完整的测试 Prompt、配置命令或用法速查表都复制不走。

## 二、三大评测文章结构模板（按题材直选）

### 模板 1：【单品深度实测 / 首发快刀斩】
- **匹配骨架**：`ticket`（汇芯红·票据封面）
- **推荐字数**：1500–2200 字｜**真图数量**：6–10 张（含 ≥1 张动图 GIF 或核心界面实拍）
- **推进结构**：
  1. **票据封面卡**：亮出工具名、实测星级、S/A/B/C 等级与一句话结果结论。
  2. **01 开篇释放结果**：用具体业务场景开场（1–2 段内必见首张成品大图或 GIF），直接展示用上它之后省了多少力、拿到什么惊艳结果。
  3. **02 核心功能与方法拆解（原件块 ①）**：手把手讲清楚最核心的 2–3 个实用功能怎么用，用代码块或表格完整贴出**执行命令 / Prompt 原文 / 目录规范**，让读者能照着立刻复现。
  4. **03 3 分钟领用与配置指南（原件块 ②）**：给出零门槛安装或上手步骤 + 可直接复制的《安装与日常使用指令卡》。
  5. **04 底层原理与人文延伸**：用通俗类比讲透它为什么好用的底层原理（如母语意图层 vs 机器契约层），再结合一人公司实战稍微延伸一点人文思考（工具越多越要给大脑做减法），温暖有力地收尾。

---

### 模板 2：【多模型 / 多工具同题横评】
- **匹配骨架**：`magazine-card`（汇芯红·杂志快讯封面 + 横向滑动目录）
- **推荐字数**：2000–3000 字｜**真图数量**：8–12 张（每轮对比必有同框或连续实拍图）
- **推进结构**：
  1. **杂志快讯开篇卡**：划掉一句旧认知，用红黑大字亮出本次横评的最大结论。
  2. **01 省流结果总表先行（第一屏直接给答案）**：开篇 2 段内直接上 **《横评结果与路由总表》**（维度：速度 / 质量 / 成本 / 最佳适用场景），第一时间释放结论。
  3. **02 实测方法与标准考卷（原件块 ①）**：交代测试环境，贴出本次横评统一使用的 **标准测试 Prompt / 任务单代码块**，告诉读者怎么测、怎么用。
  4. **03 逐轮实操展示与组合拳方案（原件块 ②）**：展示各工具的高光产出截图与效率数据，给出《不同预算/角色的最优组合配置单》。
  5. **04 底层原理与人文延伸**：从模型架构或产品哲学角度点透差异背后的原理，并延伸到创作者与一人公司如何驾驭工具矩阵的人文思考。

---

### 模板 3：【Agent Skill / MCP / 新功能深扒】
- **匹配骨架**：`classic-edit`（汇芯红·经典编辑引言卡 + 三列看点 + 编号章节）或 `ticket` / `journal`
- **推荐字数**：1500–2200 字｜**真图数量**：6–10 张
- **推进结构**：
  1. **引言卡 + 看点短标**：点明这个 Skill 替你拿到了什么结果。
  2. **01 先看跑通后的交付结果**：第一屏直接晒出用该 Skill 跑出来的最终成品截图/录屏，并给出开源/领用链接。
  3. **02 核心巧思与实操方法（原件块 ①）**：讲清楚它最懂业务的设计巧思与使用流程，贴出《功能对照表 / 目录速查表》。
  4. **03 3 分钟极速安装与上手（原件块 ②）**：贴出可直接复制的 **安装配置命令 / 调用口令卡**，让读者三分钟搬回家。
  5. **04 底层原理与人文延伸**：稍微延伸讲一下背后的工作流原理与一人公司减法哲学，升华收口。

## 三、标题实验室 2.0（每次出 6 个实质差异候选，严禁喊麦）

1. **三要素硬公式**：**「具体数字/成本 + 反差/冲突结果 + 读者可拿走物/高权流量词」**。
2. **字数控制**：14–22 个汉字为最佳视觉甜区；涉 `WorkBuddy`、`Claude`、`DeepSeek`、`Cursor` 等高权词必须保留在标题前半段。
3. **绝对禁区**：
   - 禁喊麦夸张词：震惊、炸裂、封神、天花板、遥遥领先、吊打、最屌、唯一、100%。
   - 禁中庸解释尾：严禁在有张力的标题后面接「但人还得盯着」「各有优劣」这类卸力废话。
   - 禁说明书裸标题：严禁「XX 模型 2.0 深度评测」「XX 工具使用指南」。
4. **高命中示范**：
   - *花钱实测型*：`花 280 元连测 4 款编程 AI，我把最火的那个退订了`
   - *同题反差型*：`同一份 50 页合同丢给 3 个大模型，免费的赢了 199 的`
   - *Skill 生产力型*：`把这个飞书 Skill 塞进工作流后，我砍掉了每天 2 小时的周报`
