# 02 · 文章结构与四大实战模板（2.0 高密度版）

> 🔴 **2026-11 重大升级（废除旧版「一句一段」与繁琐填表）**：
> 1. **彻底废除「按句号切开、一句一段」**：段落统一按 **2–3 行自然短段（40–60 字，校验上限 ≤80 字）** 切分，严禁出现连续 3 段 ≤15 字的电报碎句。
> 2. **高价值原件硬闸（≥2 个）**：每篇评测必须包含 **至少 2 个可直接复制拿走的原件块**（` ``` ` 代码围栏渲染出的完整测试 Prompt、配置单、算账对比单或带 `✓ / ✗` 的选型路由表）。
> 3. **开篇三件套去重硬闸**：骨架自带的「开篇卡金句」→「目录/看点」→「第一章标题」→「正文首段」，四者语义必须层层递进，严禁把同一句话车轱辘说三遍。

## 一、五个一票否决项（触犯任意一条直接打回重写）

1. **无独家发现**：把文章里的模型/工具名字挡住，整篇话依然成立（全是正确的行业废话）。
2. **开篇慢热无现场**：前 2 段还在背诵“随着 AI 大模型飞速发展”，没有具体业务任务、痛点或真金白银的账单。
3. **只夸不骂像软文**：全文找不出一处真实翻车、报错截图或已知限制（哪怕是推荐向评测，也必须明确指出它在什么场景下会拉胯）。
4. **结尾和稀泥**：横评结尾写“各有千秋，大家按需选择”，不敢明确给出「谁现在立刻换、谁千万别掏钱」的站队结论。
5. **无原件可拿走**：通篇只顾着自己嗨聊感受，读者读完连一条完整的测试 Prompt、配置命令或算账表都复制不走。

## 二、四大评测文章结构模板（按题材直选）

### 模板 1：【单品深度实测 / 首发快刀斩】
- **匹配骨架**：`ticket`（汇芯红·票据封面）
- **推荐字数**：1800–2600 字｜**真图数量**：8–12 张（含 ≥1 张动图 GIF）
- **五幕推进结构**：
  1. **票据封面卡**：亮出工具名、实测星级、S/A/B/C 等级与一句话狠结论。
  2. **01 现场立靶与结论先行**：用昨晚/今天刚跑的具体业务难题开场（1–2 段内必见首张成品大图或 GIF），直接挑明它到底值不值得升/买。
  3. **02 亮出压测标尺（原件块 ①）**：交代 3 个由浅入深的真实测试场景，用代码块完整贴出**测试 Prompt 原文或执行命令**，让读者能自己复现。
  4. **03 惊艳高光 vs 翻车抓包（核心证据区）**：
     - 哪一题它干得比人工还漂亮（配实操截图卡 + 耗时数字）；
     - 哪一题它当场翻车或触发隐藏限制（配报错/翻车红框截图 + 绕过方法）。
  5. **04 算清真金白银与选型边界（原件块 ②）**：
     - 官网最新套餐/API 价格（标查询日期）+ 真实消耗账单；
     - 用代码块或对照表给出带 `✓ 闭眼入` / `✗ 劝退` 的人群路由清单。

---

### 模板 2：【多模型 / 多工具同题死磕横评】
- **匹配骨架**：`magazine-card`（汇芯红·杂志快讯封面 + 横向滑动目录）
- **推荐字数**：2400–3500 字｜**真图数量**：10–15 张（每轮对比必有同框或连续实拍图）
- **五幕推进结构**：
  1. **杂志快讯开篇卡**：划掉一句市场盲目吹捧的旧认知，用红黑大字亮出本次横评的最大反差结论。
  2. **01 省流胜负总表先行（第一屏直接给答案）**：
     - 开篇 2 段内直接上 **《横评胜负与路由总表》**（维度：速度 / 准确率 / 审美或代码跑通率 / 单次成本 / 一句话站队），不逼读者翻到底才看结果。
  3. **02 公平竞赛规则与公共考卷（原件块 ①）**：
     - 声明测试环境（版本、联网状态、预算上限），贴出本次横评统一使用的 **标准压测 Prompt / 原始任务单代码块**。
  4. **03 逐轮同题死磕（Round 1 ~ Round 3）**：
     - 每一轮只测一个硬指标：先摆出参赛选手的真实输出截图/GIF，再用数据说话（谁快了几秒、谁漏了几个字段、谁的代码一次点亮），**每轮当场宣布单轮赢家**。
  5. **04 终极站队与组合拳方案（原件块 ②）**：
     - 给出《不同预算/角色的最优组合配置单》（例如：日常主力用 A + 复杂推理切 B + 免费兜底用 C）。

---

### 模板 3：【Agent Skill / MCP / 新功能深扒】
- **匹配骨架**：`classic-edit`（汇芯红·经典编辑引言卡 + 三列看点 + 编号章节）或 `journal`（内刊手记）
- **推荐字数**：2000–3000 字｜**真图数量**：8–12 张
- **五幕推进结构**：
  1. **引言卡 + 三看短标（每格 3–6 字）**：点明这个 Skill 到底替你省掉了哪道苦力活。
  2. **01 先看跑通后的交付物**：第一屏直接晒出用该 Skill 自动跑出来的最终成品截图/录屏 GIF，立住“真跑通”的信任锚点。
  3. **02 三步极速拆解与配置原件（原件块 ①）**：
     - 讲清楚它的底层调用逻辑（用生活化类比，不堆术语）；
     - 贴出可直接复制的 **安装配置命令 / JSON 配置块 / 调用口令**。
  4. **03 连跑 10 次踩出来的 3 个隐形坑（原件块 ②）**：
     - 鉴权坑、限流坑、格式漂移坑，配真实报错截图与《避坑自检清单代码块》。
  5. **04 投入产出算账与平替对比**：和手动操作或同类旧插件比，到底省了多少时间与 Token。

---

### 模板 4：【智商税打假 / 避坑实录】
- **匹配骨架**：`ticket`（票据封面，Grade 标 `C` 或 `D`）
- **推荐字数**：1500–2200 字｜**真图数量**：6–10 张
- **推进结构**：
  1. 晒出真实付费账单或耗时记录 → 2. 官方宣传口径 vs 本机实测拉胯同框对比（3 个具体落差） → 3. 客观保留它唯一能用的 1 个小长板（不搞情绪化黑稿） → 4. 附上 **免费/更稳的平替方案与迁移配置原件块（≥2 个）**。

## 三、标题实验室 2.0（每次出 6 个实质差异候选，严禁喊麦）

1. **三要素硬公式**：**「具体数字/成本 + 反差/冲突结果 + 读者可拿走物/高权流量词」**。
2. **字数控制**：14–22 个汉字为最佳视觉甜区；涉 `WorkBuddy`、`Claude`、`DeepSeek`、`Cursor` 等高权词必须保留在标题前半段。
3. **绝对禁区**：
   - 禁喊麦夸张词：震惊、炸裂、封神、天花板、遥遥领先、吊打、最屌、唯一、100%。
   - 禁中庸解释尾：严禁在有张力的标题后面接「但人还得盯着」「各有优劣」这类卸力废话。
   - 禁说明书裸标题：严禁「XX 模型 2.0 深度评测」「XX 工具使用指南」。
4. **高命中示范**：
   - *花钱实测型*：`花 280 元连测 4 款编程 AI，我把最火的那个退订了`
   - *同题反差型*：`同一份 50 页合同丢给 3 个大模型，免费的赢了 199 的`
   - *Skill 生产力型*：`把这个飞书 Skill 塞进工作流后，我砍掉了每天 2 小时的周报`
